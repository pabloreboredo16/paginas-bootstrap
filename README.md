# 🎨 Colección de Prácticas Bootstrap

Repositorio con maquetaciones y proyectos web creados con **Bootstrap 5**.

🌐 **Ver catálogo:** [pabloreboredo16.github.io/paginas-bootstrap](https://pabloreboredo16.github.io/paginas-bootstrap/)

---

## 📂 Proyectos y Prácticas

* **`album.html`**: Plantilla de galeria responsiva con tarjetas de contenido y metadatos.

* **`blog.html`**: Maquetación de blog con artículos destacados y barra lateral.

* **`carrusel.html`**: Slider de imágenes a pantalla completa con controles de navegación.

* **`jumbotron.html`**: Portada estilo panel principal con imagen de fondo destacada y tarjetas informativas.

* **`masonry.html`**: Muro visual dinámico para organizar contenido.

* **`pricing.html`**: Tabla comparativa de planes de precios y suscripciones.

* **`producto.html`**: Página de producto orientada al marketing con bloques de presentación.
